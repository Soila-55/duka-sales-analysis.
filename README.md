# Duka Sales Analysis

## Project Description
This project analyzes retail sales data using Python and pandas in Google Colab.

## Key Findings
- Total orders: 1,000
- Total revenue: KSh 32,635,000
- Total units sold: 2,125
- Number of branches: 5
- Number of products: 6
- Top branch: Nairobi
- Top product by revenue: Laptop
- Top sales channel: In-Store
- Best month: March

## Files
- `duka_sales_summary.csv`: Contains the sales summary.

## Tools Used
- Python
- Pandas
- Google Colab
